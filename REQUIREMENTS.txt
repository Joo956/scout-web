5.1 ─── الأدوار ────────────────────────────────────────────────────────────

الدور          الوصول                                     رمز
─────────────  ──────────────────────────────────────────  ────
admin          وصول كامل بلا قيود — يرى كل الأقسام        🔴
               ويعدل وينشئ ويحذف في كل حاجة
subadmin       وصول محدد بالصلاحيات — يرى بس الأقسام       🟡
               المسموحة له (read/write لكل قسم)
member         وصول عضو عادي — صفحات العضو بس             🟢

5.2 ─── نظام الصلاحيات ────────────────────────────────────────────────────

الصلاحيات بصيغة section:action

القسم          صلاحية القراءة        صلاحية الكتابة
─────────────  ────────────────────  ────────────────────
members        members:read          members:write
exams          exams:read            exams:write
store          store:read            store:write
library        library:read          library:write
orders         orders:read           orders:write
news           news:read             news:write
users          users:read            users:write
badges         (عبر members)         (عبر members)

- Admin كامل: isAdmin = true → كل الصلاحيات دايمًا
- Subadmin: isAdmin = false → يفحص الصلاحيات المحددة
- Subadmin بدون صلاحيات = لا وصول

6.1 ─── إدارة الكشافين (MembersSection) ───────────────────────────────────
الصلاحية: members:read / members:write
الميزات:
  - عرض قائمة الأعضاء مع بحث وتصفية حسب المرحلة
  - إضافة عضو جديد (اسم، تاريخ ميلاد، مرحلة كشافة، بيانات الاتصال...)
  - تعديل بيانات عضو
  - حذف عضو
  - إحصائيات حسب المرحلة (أشبال، زهرات، كشاف... إلخ)
  - استيراد أعضاء من Excel
  - مسح QR للحضور
  - توليد كود كشافة تلقائي (scout_code)

6.2 ─── إدارة الحضور (AttendanceSection) ─────────────────────────────────
الصلاحية: members:read / members:write
الميزات:
  - تسجيل حضور/غياب يومي
  - عرض سجل الحضور بالتاريخ
  - مسح QR سريع للحضور (ScanPage)
  - إحصائيات الحضور

6.3 ─── إدارة الامتحانات (ExamsSection) ──────────────────────────────────
الصلاحية: exams:read / exams:write
الميزات:
  - إنشاء امتحان جديد (عنوان، مدة، أسئلة)
  - تعديل وحذف امتحان
  - عرض النتائج والموافقة عليها
  - السماح بإعادة الامتحان
  - أمان: تشفير الأسئلة، منع النسخ

6.4 ─── إدارة المتجر (StoreSection) ──────────────────────────────────────
الصلاحية: store:read / store:write
الميزات:
  - إدارة المنتجات (اسم، سعر، مخزون، صور متعددة)
  - إدارة التصنيفات ونطاق السعر
  - تحكم في إعدادات المتجر
  - صور متعددة للمنتج (links:// protocol)
  - إضافة/إزالة صور ديناميكياً

6.5 ─── إدارة الطلبات (OrdersSection) ────────────────────────────────────
الصلاحية: orders:read / orders:write
الميزات:
  - عرض الطلبات مع فلترة حسب الحالة
  - تحديث حالة الطلب (pending → processing → shipped → delivered)
  - تفاصيل الطلب والعميل

6.6 ─── إدارة الأخبار (NewsSection) ──────────────────────────────────────
الصلاحية: news:read / news:write
الميزات:
  - إنشاء وتعديل وحذف الأخبار
  - تثبيت خبر (pinned)
  - نماذج/Form للأخبار

6.7 ─── إدارة المكتبة (LibrarySection) ───────────────────────────────────
الصلاحية: library:read / library:write
الميزات:
  - إضافة كتب وملفات
  - تصنيف وبحث

6.8 ─── الشارات (BadgesSection) ──────────────────────────────────────────
الصلاحية: members:read / members:write
الميزات:
  - إنشاء وتعديل وحذف الشارات
  - 9 تصنيفات × 4 مستويات × 12 مرحلة كشافة
  - إظهار/إخفاء الشارة (visible toggle)
  - ربط الشارة بمرحلة كشافة (scout_stage)
  - حقول تقديم مخصصة (application_fields)
  - منح شارة لعضو (GrantBadgeModal) مع فلترة حسب المرحلة

6.9 ─── إدارة الحسابات (UserManagement) ─────────────────────────────────
الصلاحية: users:read / users:write (admin فقط)
الميزات:
  - إنشاء حسابات جديدة (admin/subadmin)

  - منح صلاحيات read/write لكل قسم (subadmin)

6.10 ─── استيراد من Excel (ImportMembers) ────────────────────────────────

8.4 ─── دورة حياة الشارة ────────────────────────────────────────────────

  [لا يوجد award] → pending_start → in_progress → submitted → approved
                                                    ↓
                                                  revoked

  - pending_start: طلب الشارة — في انتظار موافقة القائد
  - in_progress: تم الموافقة — العضو يعمل على المتطلبات
  - submitted: العضو قدم الأدلة — في انتظار المراجعة
  - approved: تم الموافقة — الشارة ممنوحة
  - revoked: مرفوضة/مسحوبة

8.5 ─── إظهار/إخفاء ──────────────────────────────────────────────────────
  - badges.visible = true → ظاهر في كتالوج العضو
  - badges.visible = false → مخفي من الكتالوج، لكن ظاهر في "شاراتي" لو ممنوح
  - admin يتحكم في visibility لكل شارة

8.6 ─── حقول التقديم المخصصة ─────────────────────────────────────────────
  - application_fields: JSON array من حقول مخصصة لكل شارة
  - كل حقل: { key, label, type, required }
  - types: text, number, url, date

8.7 ─── منح تلقائي ───────────────────────────────────────────────────────
  - auto_grant_rule: قاعدة منح تلقائي
  - مثال: 'attendance:80%' → منح شارة عند حضور 80%
